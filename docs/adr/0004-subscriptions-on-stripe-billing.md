# 0004. Абонементы на Stripe Billing, цена живёт в Stripe

## Контекст

Абонементы на Wix в основном оплачиваются переводом. Нужны регулярные списания, смена карты и отмена силами ученика. Остальные цены на сайте берутся из CMS и отправляются в Stripe при оформлении (см. 0001).

## Решение

Абонемент — подписка Stripe: `POST /checkout/subscribe` создаёт Checkout `mode: subscription` с `line_items: [{price: plan.stripePriceId, quantity: 1}]` и `metadata.planId`. Цена абонемента живёт в Stripe как месячный Price; в CMS у тарифа хранится только его id, а цена на сайте остаётся текстом. Состояние подписок приходит вебхуками (`customer.subscription.created|updated|deleted`, `invoice.payment_failed`) в коллекцию `subscriptions`, доступную только на чтение. Письма о неудачных списаниях шлёт Stripe, смену карты и отмену ученик делает на портале Stripe по ссылке из настроек сайта. Тариф без `stripePriceId` показывается без кнопки Subscribe.

## Почему

- Свои повторные списания по крону с сохранёнными картами. Отвергнуто: хранение карт, повторные попытки, уведомления и отмену пришлось бы писать с нуля, а Stripe Billing всё это уже умеет.
- `price_data` для подписки, как у разовых покупок. Отвергнуто: цена подписки — долгоживущий объект, на который ссылаются подписки и портал; он должен быть стабильным и существовать в Stripe, а не пересоздаваться с каждым оформлением.
- Оставить переводы. Отвергнуто: это статус-кво, ради замены которого и затевалась оплата.
- Собственная страница управления подпиской. Отвергнуто: портал Stripe даёт смену карты и отмену без кода; в настройках сайта хранится только ссылка.

## Последствия

- Две правды о цене: текст в CMS и Price в Stripe. Если они разойдутся, покупатель увидит одну цену, а заплатит другую; согласовывать надо руками.
- Цены тарифов нужно завести в каждом аккаунте Stripe: этим занимается `npm run stripe:setup`, он записывает id в `plans.stripePriceId` (см. 0006).
- Минимальный срок два месяца Stripe сам не держит. Он остаётся текстом тарифа до решения владельца, а не кодом.
- Подписки в админке только читаются: управление происходит в Stripe, сайт лишь отражает вебхуки.
